# Repository guidance

Read and follow [AGENTS.md](AGENTS.md) for the shared project instructions,
development commands, Rust/WASM boundaries, ADR rules, PR requirements, and licenses.

Before architectural changes, inspect [docs/adr/](docs/adr/). New ADRs start as
Proposed; human review is required for acceptance, and Accepted ADRs are immutable.

Use [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) for every PR
and fill all fields as described in AGENTS.md.
